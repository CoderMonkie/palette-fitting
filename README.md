# 配色试衣间 / Palette Fitting

把一套配色在 60 秒内变成可交付的界面 token，并当场验证它能不能用。

定位：有审美立场的主题 × 真实界面验证（策展 + 验证象限）。

状态：规格见 `docs/SPEC.md`。技术栈为 Vite + Lit 3 + TypeScript（无框架、无 Tailwind）。设计意图原型留档于 `/tmp/buddymux-palete/index.html`。

本地运行（依赖由用户自行安装）：

- `npm install`
- `npm run dev`
- `npm run build`（含 `tsc --noEmit`）
