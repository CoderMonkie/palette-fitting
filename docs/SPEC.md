# 配色试衣间 / Palette Fitting — 产品规格

状态：需求与规格已确认，待开发。项目根：`/Users/mac/WorkBuddy/spaces/PaletteFitting/palette-fitting`。
本文件是开发和验收的唯一事实源；变更需先改这里，再改代码。

## 1. 定位与命名

- 中文名：配色试衣间；英文名：Palette Fitting。
- 一句话定位：把一套配色在 60 秒内变成可交付的界面 token，并当场验证它能不能用。
- 象限：有审美立场的主题（策展）× 真实界面验证。不与随机配色生成器、取色器竞争。
- 核心洞察：差异化不在"能调色"，而在"调完就能看见用在哪里、能不能用、怎么交付"。

## 2. 目标用户（待验证假设）

独立开发者、小团队设计师/PM、内容创作者。共同特征：没有完整设计系统，但需要界面看起来专业。
用户画像与"60 秒 / 3 分钟"均为待验证假设，不是研究结论。

## 3. 色彩模型

### 3.1 三种可编辑角色

| 角色 | CSS 变量 | 用途 |
|---|---|---|
| 背景 background | `--palette-bg` | 页面底、导航底、侧栏底 |
| 工作面 surface | `--palette-surface` | 卡片、内容区、表单控件底 |
| 主色 accent | `--palette-accent` | 按钮、链接、激活态、强调标签 |

### 3.2 派生色（不可直接编辑，随角色自动计算）

- 正文色 `--palette-text`：从背景亮度派生——背景相对亮度 ≥ 0.35 用深色 `#2B2822`，否则用浅色 `#F5F3EE`。界面标注"正文色（自动）"并显示其与背景的对比度。
- 主色上的文字 `--palette-on-accent`：取白或黑中对比度较高者。
- 次要文字 `--palette-text-muted`：正文色按 0.72 不透明度叠加。
- 边框 `--palette-border`：当前角色色按 0.16 不透明度叠加。
- 语义色（成功/警告/错误/信息）为固定值，不参与三色编辑，避免与用户主题混淆：
  - 成功 `#2E6E56`、警告 `#9A6B1F`、错误 `#B23A2E`、信息 `#2C5F73`。

|---|---|---|---|

| 绢本 · 赭石 | `#F3ECDD` | `#FAF5EA` | `#9C6B3E` |

## 4. 信息架构与首屏

- 工具控制区固定为中性色，不随预览主题变色，避免干扰判断。
- 桌面：左侧控制栏（预置 → 三色编辑 → 调色板 → 导出），右侧预览区（场景切换 → 预览 → 可读性检查）。
- 移动：单列堆叠，控制区在上、预览在下；预置两列网格；触控目标 ≥ 44×44px。
- 首屏可见：当前主题、三色编辑入口、至少一个完整场景、对比度提示。

## 5. 首版功能范围（P0，必须实现）

1. **六套预置**：选择后编辑器与预览同步；预置本身不可改。
2. **三色编辑**：色相/饱和度/明度（HSV）调色板 + 色相条 + HEX 输入，三者同步；不接入浏览器原生取色器（点击会弹出悬浮面板，增加交互且打断开/调色同屏），仅保留只读色块展示当前色。HEX 校验，非法值有明确反馈且不静默替换。
3. **键盘可达**：调色板与色相条支持方向键微调、`role="slider"`、ARIA 值标签、可见焦点样式；全部功能键盘可完成。
4. **派生正文色与主色文字色**：按 3.2 规则自动计算，实时显示数值。
5. **四个场景预览**：内容展示页、管理工作台、数据看板、移动界面。每场景覆盖文字层级、按钮、表单、列表/表格、状态标签。
6. **交互态预览**：按钮与表单展示 default / hover / focus / disabled / error 态；含空态示例。
7. **可读性检查**：正文/背景、正文/工作面、按钮文字/主色三组对比度数值与阈值（正文 ≥ 4.5:1，大字 ≥ 3:1，组件边界 ≥ 3:1）；标注"仅针对所列组合，不代表整页合规"。
8. **草稿状态**：每套预置独立保存草稿；修改标记"已修改"；切换主题保留各自草稿；恢复当前预置丢弃该草稿。
9. **本地保存与分享**：localStorage 自动保存草稿与选中主题；URL 参数编码当前配色，打开链接即复现。
10. **导出**：复制 CSS 变量、复制 JSON token、复制 Tailwind 配置片段；成功/失败有反馈。

## 6. 明确不做（首版）

AI 自动配色、账号与云同步、社区、图片取色、设计软件插件、完整设计系统编辑器、后端与数据库。

## 7. 后续迭代（P1/P2，发布后按反馈做）

- P1：每套主题附"配方说明"（出处、适用场景、禁忌）；JSON/Tailwind 导出增强；色觉模拟（红绿色盲）。
- P2：深色变体自动派生；场景自定义；主题包导入导出。

## 8. 组件与状态约定

| 组件 | 职责 | 必须具备的状态 |
|---|---|---|
| PresetPicker | 六套预置选择 | selected / 默认 / 悬停 / 焦点 |
| RoleEditor | 三色角色切换与数值输入 | selected / 编辑中 / 校验失败 |
| ColorPad | HSV 取色 | 默认 / 拖动中 / 键盘焦点 / 值标签 |
| ScenePreview | 场景切换容器 | 四场景互斥切换 |
| Scene（各场景） | 真实界面示例 | default / hover / focus / disabled / error / empty |
| ContrastPanel | 对比度数值与判定 | 达标 / 偏低 |
| ExportBar | 复制导出 | 成功 / 失败 |

- 每屏唯一主操作：复制 CSS 变量。
- 间距遵循 8pt 栅格（4/8/16/24/32/40）；组间距 ≥ 2× 组内间距。
- 字体：正文 ≥ 14px、辅助 ≥ 12px、标题 20–28px；中文正文行高 1.6–1.9。
- 圆角统一 6–10px；不使用渐变背景、发光、毛玻璃。

## 9. 技术栈

Vite + **Lit 3** + TypeScript。静态产物，无后端、无账号、无 UI 框架。

选型依据：Lit 基于 Web Components 标准，约 5KB，提供响应式 properties 与声明式模板；官网列有 Adobe Spectrum、SAP UI5、IBM Carbon、ING Lion、Salesforce Pharos、VMware Clarity 等生产级设计系统用例，成熟度高。本工具体量小，用 Lit 避免引入完整框架；同时不用 Tailwind——Shadow DOM 样式隔离与全局原子类冲突，配色工具改用 CSS 变量（`--palette-*`）做主题，可穿透 Shadow DOM 继承。共享状态用最小订阅式 store + Lit ReactiveController，不依赖 Labs 实验性 Signals。

依赖由用户安装；代理不执行安装、build、typecheck、Git add/commit/push、部署。

## 10. 验收清单

- [ ] 六套预置的九个色值与第 3.3 节逐项一致。
- [ ] 三色在四种输入方式下同步；非法 HEX 有反馈且不应用。
- [ ] 正文色随背景亮度切换深浅，且显示与背景的对比度。
- [ ] 键盘可完成取色、角色切换、场景切换与导出；焦点可见。
- [ ] 四场景均展示文字层级、按钮、表单、列表/表格、状态标签及交互态。
- [ ] 对比度数值与手算一致，不出现"提示达标但实际不可读"。
- [ ] 草稿切换主题不丢失；恢复预置正确丢弃；刷新后本地状态保留。
- [ ] URL 分享链接在干净浏览器打开能复现配色。
- [ ] 三种导出格式内容与当前配色一致。
- [ ] 手机视口无横向溢出，触控目标 ≥ 44×44px。
- [ ] 5–8 名目标用户中至少 4 人可在 3 分钟内独立完成"选主题 → 调色 → 复制 token"。
